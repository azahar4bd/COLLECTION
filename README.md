# 💰 কালেকশন ম্যানেজার (Collection Manager)

CSV থেকে ডাটাবেজ তৈরি · GitHub-ভিত্তিক ডাটা স্টোরেজ (Neon নয়) · Netlify-এ ডিপ্লয়

## ✨ ফিচার

- **CSV আপলোড → ডাটাবেজ**: CSV আপলোড করলে মেম্বার ডাটাবেজ তৈরি হয়; নতুন CSV আপলোড করলে মেম্বার কোড অনুযায়ী মিলিয়ে আপডেট হয় (নতুন যোগ হয়, পুরনো আপডেট হয়)
- **প্রতিনিয়ত সিঙ্ক**: নির্দিষ্ট সময় পর পর GitHub থেকে ডাটা নিজে নিজে নিয়ে আসে (Auto-sync), ম্যানুয়াল 🔄 বাটনও আছে
- **পেজ ১ — বাকী / আদয় তালিকা**:
  - 🕒 কিস্তি বাকী তালিকা ও ✅ কিস্তি পেইড তালিকা — দুটোই **expand/collapse** সিস্টেমসহ
  - কলাম: মেম্বার কোড, মেম্বার নাম, সেন্টার কোড, সেন্টার নাম, কিস্তি
  - সার্চ + কেন্দ্র অনুযায়ী ফিল্টার
  - যেকোনো সারি **ট্যাপ** করলে popup-এ বিস্তারিত ডিটেইলস
  - popup-এর নিচে **টাকা আদায়ের ঘর**: কিস্তি, সঞ্চয়, DPS (মোট অটো-ক্যালকুলেট)
  - টাকা না দিলে **পরবর্তী টাকা দেওয়ার তারিখ** দেওয়ার ঘর
- **পেজ ২ — আজকের আদায়**: আজ আদয়কৃত সদস্যদের তালিকা
  - কলাম: মেম্বার কোড, নাম, সেন্টার কোড, কিস্তি, সঞ্চয়, DPS, মোট
  - নিচে: **মোট কিস্তি, মোট সঞ্চয়, মোট DPS, মোট সংখ্যা**
  - ভুল হলে রেকর্ড মুছে ফেলার অপশন, "সব রেকর্ড" ভিউ

## 🗄 ডাটা কোথায় থাকে?

আপনার GitHub রেপোতে (Neon বা অন্য কোনো ডাটাবেজ নয়):

```
data/members.json       → সদস্যদের তালিকা (CSV থেকে তৈরি/আপডেট)
data/collections.json   → আদয়ের ইতিহাস (কিস্তি/সঞ্চয়/DPS, তারিখ, পরবর্তী তারিখ)
```

## ⚙️ সেটআপ

### ১. GitHub Token তৈরি

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained token**
- Access: আপনার রেপো (যেখানে ডাটা থাকবে)
- Permissions: **Contents → Read and Write**

### ২. ডাটা রেপো তৈরি

যেকোনো GitHub রেপো (নতুন বা পুরনো) — যেমন `collection-db`। অ্যাপটা প্রথম চালুতে `data/members.json` ও `data/collections.json` নিজেই তৈরি করে দেবে।

### ৩. Netlify-এ ডিপ্লয়

**সহজ পথ (Drag & Drop):**
1. Netlify → Add new site → **Drag and drop** এই ফোল্ডারটা (`index.html`, `styles.css`, `app.js`)
2. পাবলিশ লিংক পেয়ে যাবেন — ব্যাস!

**GitHub connect (অটো-ডিপ্লয়):**
1. এই রেপোটা GitHub-এ পুশ করুন
2. Netlify → New site from Git → GitHub → এই রেপো সিলেক্ট
3. Build settings: **Build command খালি**, Publish directory: `/`

### ৪. অ্যাপ সেটআপ

প্রথমবার খুললে সেটআপ ফর্ম আসবে:
- PAT, Repo Owner (username), Repo Name, Branch (ডিফল্ট `main`) ফিল করুন
- **সংযোগ পরীক্ষা** করে **সংযোগ সেভ** করুন

> ⚠️ টোকেন ব্রাউজারের localStorage-এ থাকে — এটা ব্যক্তিগত ব্যবহারের টুল। পাবলিক রেপোয় টোকে কখনোই পুশ করবেন না।

## 📄 CSV ফরম্যাট

হেডার ইংরেজি বা বাংলা — অ্যাপ অটো-ডিটেক্ট করে, আপলোডের সময় ম্যাপিং ঠিক করে দিতে পারবেন:

```csv
member_code,member_name,center_code,center_name,kisti,savings,dps,phone
M-1001,রফিকুল ইসলাম,C-01,মিরপুর কেন্দ্র ১,500,100,300,01711000001
```

বাধ্যতামূলক: `member_code`, `member_name`, `center_code`, `kisti`
ঐচ্ছিক: `center_name`, `savings`, `dps`, `phone`

নিয়ম:
- UTF-8 এনকোডিংয়ে সেভ করুন
- কমা (`,`) সেমিকোলন (`;`) বা ট্যাব ডেলিমিটার — সব সাপোর্টেড
- বাংলা সংখ্যা (৫০০) ও ৳ চিহ্নও পড়ে নেয়
- একই `member_code` মিললে ডাটা আপডেট হবে, নতুন কোড হলে নতুন সদস্য যোগ হবে

## 📱 ব্যবহার

1. **📤 (হেডারে)** → CSV আপলোড → কলাম ম্যাপ করুন → "ডাটাবেজ আপডেট করুন"
2. **বাকী তালিকা** থেকে সদস্য ট্যাপ করুন → popup-এ কিস্তি/সঞ্চয়/DPS দিয়ে **আদয় সেভ** করুন, না দিলে পরবর্তী তারিখ দিন
3. **আজকের আদয়** পেজে আজকের সব আদয় + মোট হিসাব দেখুন
4. হেডারের ⚙️ থেকে যেকোনো সময় রেপো/টোকেন বদলাতে পারবেন
